# 🎓 Career Compass

A modern Student Career Guidance Website that helps students choose a career path and provides a complete learning roadmap.

## ✨ Features

- 🎯 Career Selection
- 📚 Skills Roadmap
- 📅 Daily Study Timetable
- 💡 Project Ideas
- 🧠 Career Recommendation Quiz
- 📈 Progress Tracker
- 📱 Fully Responsive
- 🌙 Modern Dark UI
